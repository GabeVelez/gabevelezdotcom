## Technical Specifications

### Image Requirements
- **Resolution:** 1280×720 minimum (will scale down to 320×180 in-game)
- **Aspect Ratio:** 16:9 (matches game canvas)
- **Format:** PNG with transparency support OR JPG
- **File naming:** `cutscene_abduction_01.png` through `cutscene_abduction_09.png`
- **Location:** `public/assets/cutscenes/abduction/`

### Style Guidelines
- **Art Style:** Illustrated/painted aesthetic (NOT pixel art)
- **Reference Era:** SNES/PS1 cutscenes (Metal Gear Solid, Final Fantasy VII style)
- **Color Grading:**
  - Frames 1-3: Warm, natural (oranges, purples, evening tones)
  - Frame 4: Shift begins (red button glow)
  - Frames 5-7: Heavy red tint, dramatic shadows
  - Frame 8: Black
  - Frame 9: Cool institutional tones (match cell scene)

### Text Overlay Specifications
- **Font:** Orbitron (match title screen) or Press Start 2P (retro)
- **Size:** 12-16px (readable at 320×180)
- **Color:** White with black outline/shadow for readability
- **Position:** Bottom third of screen (avoid overlapping character faces)
- **Animation:** Fade in (300ms), hold, fade out (300ms)

- Accept SPACE key to skip
- Transition to CellScene when complete

**Pseudo-code structure:**
```javascript

  constructor() {
    super("AbductionCutscene");
    this.frames = [
      { image: "cutscene_abduction_01", duration: 2000, text: ["MAY 25TH, 7:42 PM", "EN ROUTE TO BIRTHDAY PARTY"] },
      { image: "cutscene_abduction_02", duration: 2000, text: ["GUBER BLACK - CONFIRMED"] },
      // ... etc
    ];
    this.currentFrame = 0;
  }

  preload() {
    // Load all cutscene images
    for (let i = 1; i <= 9; i++) {
      this.load.image(`cutscene_abduction_${i.toString().padStart(2, '0')}`,
        `assets/cutscenes/abduction/cutscene_abduction_${i.toString().padStart(2, '0')}.png`);
    }
  }

  create() {
    // Display first frame
    this.showFrame(0);

    // Skip listener
    this.input.keyboard.once("keydown-SPACE", () => this.skipCutscene());
  }

  showFrame(index) {
    // Clear previous

    // Animate text
    // Set timer for next frame
  }

  skipCutscene() {
    this.scene.start("CellScene");
  }
}
```
